# Multi-modal black box recorder
Instructions to deploy the notebook:
- __Optional__: place a `.env` file in the same folder of the notebook. This file should contain your Groq API key, in the following format: `GROQ_API_KEY=gsk_xxxxxxxxxxx`.
- Run each cell of the notebook individually, starting from `Dependencies installation` up to `Sync mode: ON`.
- Run `Vehicle setup` cells based on the vehicles you need.
- Run each cell from `Anti-tampering system - File hashing` up to `Sync mode: OFF | Destroy all`.
- Run one of the simulation cells available, according to your needs.
- Run `Viewer setup: replay with timeline` and `Viewer opening` cells to open the graphical viewer.
